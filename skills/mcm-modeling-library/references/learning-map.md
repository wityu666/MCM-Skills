# 模型学习路线

采用先修关系而不是照搬算法数量。学过名称、看懂数学、实现通过和真实复现是不同层级，见[交接约定](contracts.md)。

| 阶段 | 学习内容 | 学习产物 |
|---|---|---|
| 基础 | 变量/单位、线性代数、微积分、概率；数值求根/插值/积分与误差 | 能解释输入输出及解析小例 |
| 数据 | 描述、分布、回归、区间、检验、指标方向和评价 | 数据口径、模型假设、独立核算 |
| 决策 | LP→整数与组合→NLP/QP→多目标/随机/鲁棒 | 目标、约束、可行性和最优性依据 |
| 时间 | 朴素预测→AR/MA/ARIMA/季节→波动与多变量 | 时点可用信息、滚动验证和区间 |
| 学习 | 线性/概率baseline→树/核→聚类/网络→复杂学习 | 训练内预处理、标签/样本单位、样本外验证 |
| 机制 | 守恒/ODE→PDE→状态空间/反馈 | 单调性、初边值、解析特例与网格/步长 |
| 随机 | 概率和Markov→MC/队列/事件→采样与个体 | 稳态、seed、热身、区间和收敛 |
| 隐变量 | 观测方程→可识别性→正则/先验→逆问题 | 可行域、尺度锚点与不确定性传递 |
| 专门域 | 信号/图像/几何、博弈/策略及领域状态模型 | 原理和范围、领域资料/依赖、专门不变量 |

全库目录由`assets/catalog.json`给出，模型来源覆盖由`assets/source-coverage.json`给出。先检索家族，再读取具体卡；无需先学完整库才解决一个题。学习计划应按用户已有数学基础和任务调整。

每张卡至少回答：解决什么问题、最低数据与假设、符号/公式、如何求解、Python/MATLAB方向、与baseline相比新增什么、怎样独立验证、何时失效和如何降级。复杂领域只理解接口或来源时保留该边界。

参考实现用已知解析值或枚举/不变量检验。资料中的插值漏项、背包超容量、数组视图交换、目标断行、权重越界、排名反向和步长比例，作为反例说明为什么验证需要对准数学目标。
