# 便携知识与来源边界

模型卡的输入、假设、公式、算法、Python／MATLAB 实现方向、验证和回退均在本包。存在原创参考实现的卡明确给出包内源码；其余卡是可按数学定义实现的指南，不冒称已有运行程序。

`materials`、`source_labels`、`distribution_source` 等字段只记录历史来源名称或发行包相对名称，不是本机路径，也不会由检索器打开。原教材、论文全文、卖家程序、工具箱和数据未随本包再分发，不是使用本包的依赖。只有已登记的实际内容 SHA 保留为内容哈希；未记录的为 `unknown`，不以名称哈希冒充内容哈希。

`material-index.json` 是 326 个历史标签的发现摘要，包含模型、方法、求解器、工具及歧义名称；不等于 326 个独立模型。`source-coverage.json` 的关联仅说明知识主题覆盖，不能证明外部程序与当前模型等同或正确。完整数学知识在本包 198 张卡里。

以前的检查／测试文件保留日期、范围、真实声明和原报告 SHA，标为 `HISTORICAL_METADATA_ONLY`。原机器命令改留命令哈希及说明；不能把这当新机器可执行命令。任何包内修改后的运行验收须绑定当前源码和新报告；Python 运行通过不能证明 MATLAB 运行通过。

少量历史核验来自已安装的第一方 docstring／源码；其 SHA、版本和检查范围保留为历史证据。原机路径已换为发行包相对名称，相关 `url` 换为官方公开文档。便携化只核验这些新入口可访问，未因此扩大模型阅读或实现验证范围。网页与原安装版本的文本不保证字节等同。
