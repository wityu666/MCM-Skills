# MCM 流程适配

本库为 MCM A、B、C 题提供模型知识和参考实现。题设与 `mcm-suite` 决定数据许可、AI 政策、交付格式及执行门禁；模型卡不能覆盖年度或题设要求。默认中文协作、英文论文。

## 任务与证据链

问题签名→baseline 及候选→变量、单位、假设→目标和约束→验证设计→实现→运行清单→独立复核→同版本结论。保留冻结 ID、输入、代码、结果哈希、回退触发器及受影响证据失效传播。学习资料由用户授权读取，不能据此扩大未来赛时私有案例或同题答案的访问许可。

## 正式 MCM 调用

在 `context.json` 和 `contracts/problem.json` 下把模型卡 ID 记入 `contracts/methods.md`。由 `mcm-model-designer` 冻结 `contracts/model.json`，Python 或 MATLAB 角色只消费当前合同。结果仍进入原运行清单、数字绑定、复核与论文链，不另造冲突状态。

将数据区分成 `model_inputs`、`background_only`、`excluded` 并保留题面页码证据。2025 C 这类只允许给定数据进入模型的题，外部资料只能作背景解释；不能由数据研究能力推断许可。所有年度与题设限制仍需当场核对。

## MCM 训练与方法学习

训练、历史复现和赛时模式按 `mcm-suite` 的模式合同执行。单独学习某方法时可用 `assets/model-contract.json` 记录局部草稿；进入正式设计后交回 MCM 模型合同。合成数据明确标注，不作观测事实。用户只要某方法推导或小实现时，不强行产出整篇论文或全部交付门禁。
