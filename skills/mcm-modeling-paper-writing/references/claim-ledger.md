# 内部主张表

适用于重要结论分散在摘要、正文、图表和结论中的稿件。它补充现有数值绑定/复核，不取代它们；局部改写没有这份表也可以完成。

`freeze_id`沿用当前合同。`evidence`登记实际文件、SHA-256、同版冻结ID、证据类别及真实复核状态。`claims`登记自拟主张、稿件位置、范围、证据ID与强度；不将内部ID印进论文。模板是DRAFT示意，需要填入实际证据，不把占位项改为PASS冒充复核。

| strength | 允许表达及需要的证据 |
|---|---|
| descriptive | 描述当前结果或限定的训练/拟合表现；不因此宣称泛化 |
| validated | 指定范围的样本外、独立或解析检查；写清检查对象，不泛化到未测情景 |
| global_optimal | 指定可行域的完整枚举或有效最优性证书；求解器SUCCESS/PSO收敛不够 |
| causal | 有效识别设计及假设；相关系数和重要性图不够 |
| significant | 检验方法、样本范围、阈值及效应；字段存在不证明检验适用 |
| robust | 实际扰动因素、范围和验证；局部检查只支持对应局部结论 |
| goal / proposal / hypothesis | 未报告的目标、建议或假说，reported=false；不是已完成结果 |

脚本校验采用声明的证据类型，不读取推理内容来证明该标签。人工须检查类型是否真实、范围与当前主张是否一致、哈希文件是否确有支持、比较对象/单位/不确定性是否足够。静态通过仍可能包含错误、欺骗性标签或错误解释。

调用时表与证据必须位于`--root`内；输出不得覆盖表/证据。当前报告主张所引用的证据若缺失、变更字节、失败、异版本或类型不足，会在该主张下报告；未被引用的登记证据不参与主张验收，预检通过不表示它们有效。证据记录本身的字段/类型错误仍是结构错误。当前支持的类别是上表对应的常见交接语义；没有合适类别时保留真实语义复核记录，而非换一个标签让脚本通过。

JSON中重复键、非有限数值、空白主张ID和非64位十六进制SHA属于结构错误；实际数值零不因布尔真值被当成缺字段。此检查只核声明的结构、链接与文件完整性，不能证明效应、检验、单位或主张本身正确。
