# MCM 数据与资料研究

先读 [共享合同](../mcm-suite/references/contracts.md)。本模块区分题设观测、外部观测、文献参数、团队假设和模拟情景，避免让模型把不同来源的数据混作事实。

## 前置

核对 `context.json` 的 MCM A/B/C、模式、年份，读取问题合同的任务和数据缺口，以及 `rules.json` 的资料与工具政策。规则证据未齐时可以整理已有输入和可逆研究，保留未核验状态；不能据此声明正式可提交。

## 行动

1. 优先读取题面、官方附件和更正。冻结工作副本，检查字段、类型、缺失、重复、覆盖范围、时间标签、粒度和单位；题设要求的数据范围不能被更方便的外部数据静默替换。
2. 把每个资料需求映射到任务或参数。确需外部来源时优先官方统计、原始数据发布者、机构数据库和原始科学文献，保留直接来源及下载版本。搜索摘要或聚合转载只能作定位线索，不能替代已查看的原始依据。
3. 为每个来源登记共享 `sources/sources.csv` 的 `id,url,title,accessed_at,usage,kind,local_path,sha256,license,limitations`；`id` 保持唯一稳定。无法取得本地副本或许可不明时写明限制，不伪造哈希或授权。
4. 记录数据观测期、发布/修订日期及 `as-of` 截止时间，区分获取时间和数据时间。历史复现遵守当时可获得的信息边界；使用后来修订值或事后信息时显式说明，预测验证避免未来信息泄漏。
5. 核对地区、群体、抽样定义、价格基期、货币、单位、时区和时间频率；任何换算、重采样、缺失处理或合并保留原字段、公式及对应来源。论文引用只能覆盖来源真实支撑的事实。
6. 没有可用观测时，交付有依据的参数区间或明确标为假设的情景，安排敏感性与不确定性分析。模拟值、插补值、专家式估计和模型输出不得冒充观测；无法识别的参数不得用看似精确的单值掩盖。
7. `mode=live` 时不联系团队外人员为当前赛题提供解题建议、数据定制或实质研究帮助，不向外发送题面或队伍方案。公开资料查阅、AI 工具使用和真人帮助分别记录并按当年规则核验；AI 可以使用不意味着真人外援可用。需要外部协作的练习或复现任务也须有用户授权。

## 输出与退出

- `sources/sources.csv`：字段完整、来源可复查、用途与限制清楚。
- `sources/research-notes.md`：任务／参数到来源 ID 的映射，数据字典、as-of 口径、单位换算、许可与覆盖缺口、观测和假设分类、仍无法确认的事实。
- 可用数据工作副本及哈希；清洗转换过程交编码模块实现，未实际清洗的材料保持原始状态。

来源足以支撑当前模型输入时交 `$mcm-model-designer`；输入不足时给出可执行的情景或降级选项。不可用数据影响的问题边界回传 `$mcm-problem-analyst`，不在研究笔记中静默改题。关键来源无从核实则停止依赖该来源的结论，独立研究可以继续。

## 变更与失效

外部数据更新、修订、单位或 as-of 边界改变后保留旧快照，生成新版本，通知依赖该来源的模型与运行重新核验。来源只作定位线索时，不允许其进入已冻结的事实或数值证据链。
