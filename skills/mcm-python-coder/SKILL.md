# MCM Python 编码

协作用中文，论文正文、图表标题与图例用英文，除非用户另有要求。Python 与 MATLAB 是可选分支；用户选择 Python 后，不要求再用 MATLAB 重写一遍。

## 前置与范围

先读 [共享合同](../mcm-suite/references/contracts.md)，核对 `context.json`、本年度 `rules.json`、`contracts/problem.json` 和 `contracts/model.json`。仅处理 MCM A/B/C；`live` 模式必须遵守已核验的当届规则与 AI 披露要求。缺少年匹配规则时可整理本地输入、检查已有代码与环境，但不把规则未明的 AI 工作当成允许的赛时成果。

编码需要有效 `freeze_id`、明确的小问、输入字段/单位、模型公式与约束、输出要求和 `verification_plan`。会改变模型或答案的缺项回传模型设计；不以默认值偷偷补齐。可以先做不依赖缺项的环境检查与数据读取。

`reproduce` 模式按用户提供的材料保留原模型、参数和代码路线，记录必要的兼容修复；不把重新设计的模型冒充原结果。原始题面与数据只读，输出写入项目工作区。

## 实现与运行

- 记录输入 SHA-256、Python 解释器、关键依赖/求解器版本和运行命令。已有环境能完成工作时复用；确需安装依赖则用项目独立环境，记录实际版本，不无故升级可用环境。
- 根据模型合同先产出可解释 baseline，再实现候选模型；统一数据切分、指标和后处理。合同只要求单一模型时不额外扩张比较任务。
- 输入路径、输出目录、seed 和参数使用 CLI 或配置文件，避免个人绝对路径与交互式 `input()`。拆开读取、求解、评价和导出；异常保留 traceback，并返回非零退出码。
- 检查缺失、重复、范围、单位、样本量和泄漏。固定实际使用的随机源；随机结果按计划汇总分布或区间，不挑最好 seed。
- 先跑小样本，再按时间/内存预算正式运行。优化输出保存决策变量、目标、约束余量与求解状态；预测输出保存切分和逐样本预测；仿真输出保存参数与重复结果。
- 在新进程执行记录命令，检查真实输出的字段、行数、排序、精度、有限值与预定验收条件。运行未结束或日志不全时不冻结。
- 每张论文图保留机器可读图源数据、生成代码和参数；使用英文标签、单位和可读图例，预测/随机图显示切分或不确定性，在论文尺寸检查裁切与可读性。

## 输出与交接

生成 `results/run_manifest.json`，按共享合同绑定 `freeze_id`、可选 `run_id`、代码/配置/输入/环境/输出的实际路径与 SHA-256，并保存复现命令、日志和失败/降级说明。保留每次运行的独立目录，当前清单指向本次结果。

生成 `results/numeric_bindings.json`：为拟进入摘要、结论、核心表图的数值登记 `id/file/selector/expected/abs_tol/rel_tol/unit`。`file` 指向机器可读真实结果，CSV 行号是从 0 开始的数据行；容差来自验证计划，不按已看到的差异放宽。

把模型合同、清单、数值绑定、源码/配置/依赖记录、日志、结果表、图源与限制直接交给 `$mcm-result-verifier`。数值绑定能定位某数值，不等于模型正确；论文确定性结论需引用当前冻结版本的有效复核证据。

## 失败与失效传播

- 超时、不可行、缺依赖或候选效果不足：保存失败证据，采用合同已有的可行 baseline/降级路线；没有可接受回退时报告具体阻断与可继续的小问。
- NaN/Inf、单位冲突、输出缺项：定位后修复并重跑受影响结果，不手改最终结果表。
- 代码、输入、参数、依赖或模型变更后创建新运行；模型语义变化还需新 `freeze_id`。按共享合同将受影响的复核、数值绑定与论文结论标记 `STALE`，重算并交接受影响范围，不要求无关小问重复求解。

## 结果到论文的解释交接

为核心表图和数字附上可读的解释说明：对应任务、输入/样本与时点、输出对象及单位、比较对象、计算/采样方式和当前验证范围。将观测、估计、预测、情景模拟、训练误差与样本外指标分别标明；不在图标题或说明中把可行解称全局最优、局部扰动称全面稳健。多面板图可以服务一个主要分析任务，说明各面板的关系，不强制每图固定句数。

说明用于交接，不提前代替独立复核。内部RID/FIG/TAB或数值ID保留在清单，成稿以真实数值、科学结论、图表号和引文表达。需要组织论文语言时按需调用[$mcm-modeling-paper-writing](../mcm-modeling-paper-writing/SKILL.md)，继续遵守本技能的冻结与复核门。
