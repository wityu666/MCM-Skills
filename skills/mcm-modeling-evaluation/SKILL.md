# MCM 综合评价、降维与排名

本技能用于 MCM A、B、C 题的赛时建模、历年题训练与指定材料复现。默认中文协作，完整中英两版论文交付沿用 `mcm-suite` 约定，英文版用于正式提交；Python 与 MATLAB 按当前主路线选择；年度规则、数据许可、冻结与交付由 `mcm-suite` 及当前题目合同负责。

先读 [共享合同](../mcm-modeling-library/references/contracts.md)，按目的读取 [模型卡](references/cards.json)。PCA主卡归本家族；降维不自动提供合理排序，数据方差权重也不自动代表用户偏好。

模型知识、公式、实现方向和已有原创参考脚本随本技能集发布，无需作者机器或原资料目录。来源标签只作溯源；带 `HISTORICAL_METADATA_ONLY` 的旧证据不验收当前包，运行状态以当前源码对应的新报告为准。

## 建模

- 排除对象编号等非解释变量，登记指标含义、单位、收益/成本/区间方向、缺失与常量。先说明任务要等级、排序、效率、潜变量还是稳定的建议。
- 方向转换、尺度变换、赋权和聚合分别声明。AHP权重来自判断，熵权来自当前样本差异；不能互相冒充。冻结RI表依据，处理1/2阶及正互反边界。
- PCA说明中心化/标准化、保留维数、载荷与方差；若用得分排名，另定义符号/权重及业务解释。FA声明潜变量与噪声，旋转不改变成分唯一可识别性。
- DEA说明投入/产出、规模报酬、方向与可比较对象；模糊评价说明隶属函数和合成算子，模糊隶属度不能自动当概率。

## 验证

从等权或可手核小矩阵baseline开始，检查方向、尺度、权重和、零/常量列、完全相同对象、排名扰动与指标删减。PCA/FA检验重构和协方差，DEA独立重算效率LP与可行性；没有同一解释目标的baseline不机械比大小。

熵权与TOPSIS可用 [原创参考实现](scripts/entropy_topsis.py)。实现显式剔除无差异列，等同对象返回并列；全常量数据输出无排名信息，不制造优劣。Python测试范围以证据为准，不宣称MATLAB已运行。

## 交接与失效

交付指标字典、变换、权重来源、聚合公式、排序/分数及敏感性；源数据、参数、样本集合或目标解释变化后重验相关证据。知识等级不能由一个脚本测试推广到整个评价家族，只有完成实际任务验证才能用于定稿结论。

知识与实现核验范围见 [本模块验证记录](references/validation_report.json)；来源状态以卡中的references与本机一手文档记录为准。
