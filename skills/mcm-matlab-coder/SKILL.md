# MCM MATLAB 编码

协作用中文，论文正文、图表标题与图例用英文，除非用户另有要求。MATLAB 与 Python 是可选分支；不为满足流程而强制重复实现。

## 前置与范围

先读 [共享合同](../mcm-suite/references/contracts.md)，核对 `context.json`、本年度 `rules.json`、`contracts/problem.json` 和 `contracts/model.json`。仅处理 MCM A/B/C；`live` 模式必须遵守已核验的当届规则与 AI 披露要求。规则未明时可盘点环境和本地输入，不把未经规则确认的 AI 求解当成可提交成果。

需要有效 `freeze_id`、明确的小问、字段/单位、公式与约束、输出和 `verification_plan`。影响答案的缺项回传模型设计；先继续不依赖缺项的读取与环境诊断。`reproduce` 模式保留用户指定的原模型、参数和代码，兼容修复单独登记。原始题面与数据只读。

## 环境与实现

- 检测实际 MATLAB 路径、`version`、`computer`、`ver` 和所需工具箱许可证；用 `which -all` 排查关键函数被同名文件遮蔽。安装应用不代表全部工具箱可用。
- 只加入本项目必要源码目录；检查外来代码来源和兼容性，不为绕过许可证或平台问题加载未知 MEX/DLL。缺能力时采用合同回退；若需改成 Python 分支，向用户说明变更并沿用其已有选择授权。
- 主流程写成接收配置的函数。参数、输入、输出和 seed 可配置，使用 `fullfile`，避免依赖 base workspace、全局 `cd`、`clear all` 或交互弹窗。
- 入口固定 `rng(seed, "twister")`，记录随机源与实际参数。保存清洗数据、决策/预测、指标、图源、日志和异常；异常打印完整报告并使批处理失败。
- 按合同先建立可解释 baseline，再运行候选模型；共享切分、评价口径和后处理。只要求单模型的任务不扩张比较任务。
- 在小实例检查数据流与约束后正式运行。独立重算目标/指标与硬约束，随机模型保存重复结果及区间；候选超时按预定预算回退。
- 用新的 MATLAB 进程运行 `-batch`，保留命令、退出码与日志；检查真实输出字段、行数、排序、有限值和验收条件，不能把静态读码说成实际求解。

## 输出与交接

按 [共享合同](../mcm-suite/references/contracts.md) 生成 `results/run_manifest.json`，记录当前 `freeze_id`（有 `run_id` 时一并记录）、输入/源码/配置/环境/输出的实际路径与 SHA-256、版本与许可记录、seed、复现命令、日志和降级说明。每次运行保留独立目录，不覆盖旧冻结结果。

保存机器可读的 CSV/JSON 指标与结果；`.mat` 可以保留完整状态，但论文数字应能通过公开字段提取。生成 `results/numeric_bindings.json`，登记核心数字的 `id/file/selector/expected/abs_tol/rel_tol/unit`；CSV 行号是从 0 开始的数据行，容差由验证计划预定。

论文图使用英文标签、单位和可读图例，以 `exportgraphics` 等方式批量导出；保留图源、绘图函数和参数，在论文尺寸检查裁切。把模型合同、清单、源码/配置、工具箱记录、日志、表图源、数值绑定和限制交给 `$mcm-result-verifier`。运行成功或 MATLAB 自报最优不能单独支持论文确定性结论。

## 失败与失效传播

- 工具箱/许可证不可用、不可行或超时：保存诊断，尝试合同授权的可行 baseline；没有回退时列明阻断，并继续不受影响的小问。
- 出现 NaN/Inf、编码/路径错误或输出不符：修复源代码后重跑受影响结果，不手改最终表格。
- 输入、源码、参数、工具箱或模型改变后创建新运行；语义改变还需新 `freeze_id`。将对应复核、数值绑定和论文结论标记 `STALE`，重算受影响部分并再次交接。

## 结果到论文的解释交接

为核心表图和数字附上可读的解释说明：对应任务、输入/样本与时点、输出对象及单位、比较对象、计算/采样方式和当前验证范围。将观测、估计、预测、情景模拟、训练误差与样本外指标分别标明；不在图标题或说明中把可行解称全局最优、局部扰动称全面稳健。多面板图可以服务一个主要分析任务，说明各面板的关系，不强制每图固定句数。

说明用于交接，不提前代替独立复核。内部RID/FIG/TAB或数值ID保留在清单，成稿以真实数值、科学结论、图表号和引文表达。需要组织论文语言时按需调用[$mcm-modeling-paper-writing](../mcm-modeling-paper-writing/SKILL.md)，继续遵守本技能的冻结与复核门。
