# MCM 英文论证检查

与通用论证协议配合，按当前任务选择检查。以下是证据问题，不是固定句式、句数、段数或“高级词”配额。

## Summary Sheet 与任务正文

先确定本稿实际能回答什么。摘要给关键答案、对象/单位/比较与范围，并交代使读者理解答案所需的方法；算法名只用于定位。结果尚未验证时维持草稿状态，不用 plausible 数字补空。摘要内的 accuracy、robustness、novelty、optimality 和 generalizability 均须找到正文中的实际依据；结论较弱时同步收紧标题和 memo，而非只在末尾补一段局限。

方法段说明接口：观测或输入是什么，输出服务哪个任务，哪些假设使推导成立，基础模型为何足够或为何须改动。解释参数是题设值、文献值、估计值还是情景值。选择多个模型时说明每个新增模块解决何种已有不足，输入如何接到下游，是否有可比较 baseline；不能用模型清单替代建立过程。

## 结果到结论的证据强度

| 结论对象 | 正文需要说明 | 容易写过强的位置 |
|---|---|---|
| 观测/估计/反演 | 测量或估计来源、尺度、识别条件与误差 | 拟合参数被当作已确定现实事实 |
| 未来预测 | 预测起点、当时可用特征、训练/验证范围与失效 | 随机 CV 或训练误差被称时间外准确 |
| 优化方案 | 目标、单位、域、约束、求解终止及最优性依据 | 启发式返回方案被称保证全局最优 |
| 群体/生态/动力学模拟 | 初值、参数、情景、守恒/边界与数值检查 | 趋势合理或热图漂亮被称实测验证 |
| 解释与政策效应 | 关联/预测贡献/反事实的不同对象及识别假设 | SHAP、相关系数、断点或 DID 名称被当因果证明 |

英文主语和动词应让读者辨认谁观察、估计、预测或检验了哪个对象。模型内现象和现实机制分开；结果描述、机制解释与规范建议分开。时态随实际过程、结果和一般规律保持一致，不为学术感堆抽象名词或宣传形容词。

## 验证、敏感性与限制

说明指标的样本、权重、量纲与聚合方式，核对 MAE/RMSE 等可用不变量；数值冲突未解释时不写高准确性。confidence、prediction、credible interval 和经验范围分别命名；名义水平、实际覆盖、测试范围和区间宽度都影响可靠性判断。期望计数不直接充当发生概率，概率需符合实际事件定义与校准证据。

敏感性以当前风险选输入和范围，说明保持不变的量、是否重解、输出变化和含义。高敏感可能要求更精确测量；低敏感只支持所检范围。有限差分/有限体积的收敛、随机重复的误差、超参数比较、数据扰动和政策变化各自解释；不能把确定性网格扫描称 Monte Carlo，也不把改变 CV 折数当全部稳健性。

限制指向结论：观测稀缺、采样失衡、外生特征未来不可得、潜变量未测量、尺度不可识别、地域/时间窄、目标不含利益冲突或数值裁剪等，会限制哪些推荐。未检测到不是已不存在；未拒绝假设也不是证明其为真。保留失败与修补过程，说明修补是否产生新的偏差；未来方法只作为未执行建议。

审阅需结合当前证据内容。静态链接、标签、哈希或语言检查不能判数学正确；涉及机制、目标、约束或关键量的疑点交回模型/结果复核，纯表达修订仍更新母版、导出与 PDF 审阅。
