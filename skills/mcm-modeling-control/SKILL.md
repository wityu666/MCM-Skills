# MCM 控制、估计与系统辨识

本技能用于 MCM A、B、C 题的赛时建模、历年题训练与指定材料复现。默认中文协作，完整中英两版论文交付沿用 `mcm-suite` 约定，英文版用于正式提交；Python 与 MATLAB 按当前主路线选择；年度规则、数据许可、冻结与交付由 `mcm-suite` 及当前题目合同负责。

先读 [共享合同](../mcm-modeling-library/references/contracts.md)，按对象和任务读取 [模型卡](references/cards.json)。状态空间是表示，Kalman是估计，PID/LQR是控制策略，不能按接口数量视为不同物理模型。

模型知识、公式、实现方向和已有原创参考脚本随本技能集发布，无需作者机器或原资料目录。来源标签只作溯源；带 `HISTORICAL_METADATA_ONLY` 的旧证据不验收当前包，运行状态以当前源码对应的新报告为准。

## 设计

- 明确连续/离散时间、采样周期、状态、测量、输入、延迟、执行器界和噪声；辨识数据保留时间顺序及输入激励。模型输入来自实际允许数据，教学参数标情景。
- 状态空间检查维数、可控/可观测性和稳定性；ARX检查输入激励、滞后阶数、残差相关和样本外多步预测，不把拟合误差当闭环能力。
- PID声明比例/积分/微分形式、微分滤波、采样和抗积分饱和；LQR明确Q/R、控制幅值与模型误差。无限时域LQR稳定条件和无硬约束假设不能静默省略。
- Kalman声明线性状态/观测与过程/测量噪声协方差，区分估计误差与实际过程变化；Q/R不是为平滑曲线随意调的参数。

## 验证与交接

按卡选择可手核标量系统、开环/固定控制baseline、解析阶跃、Riccati残差、创新白噪声/覆盖和扰动情景。实际部署前检查饱和、延迟、噪声和建模误差；仿真可行不表示实物控制已获授权或验证。

Python/MATLAB接口是实现方向，按宿主版本与依赖核对。无运行证据只交付设计/静态审阅，不声明控制性能通过。输出对象/观测器/控制律合同、时间切分、参数来源与可复核指标；改变采样、模型、Q/R、控制参数或验证场景后更新冻结与相关失效链。

知识与实现核验范围见 [本模块验证记录](references/validation_report.json)；来源状态以卡中的references与本机一手文档记录为准。
